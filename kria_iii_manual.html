kria iii

monome grid one — 4-track midi step sequencer — v1.4.0

navigation — row 8

steps 1-4: tracks · steps 6-9: pages · steps 11-13: overlays (hold) · step 15: scale · step 16: pattern / transport blink
  • steps 1-4: select active track. full brightness = selected. dim = muted.
  • step 6: trigger page. press again = ratchet sub-page (blinks). step 7: note page. press again = alt note (blinks). step 8: octave page. press again = velocity (blinks). step 9: duration page.
  • step 11: loop overlay (hold). step 12: time division overlay (hold). step 13: probability overlay (hold).
  • step 15: scale page (hold). step 16: pattern page (hold). when transport is running, step 16 pulses to beat.
  • mute: hold loop (step 11) + press a track button.
  • track copy: hold source track button, press destination — copies current page data.
  • track clear: hold track button ~2s — resets current page data for that track.
  • time / config / play / reset are also available while holding loop, time division, or probability overlays (row 7).

trigger page

step 6 — row 8

rows 1-4: tracks 1-4 · row 7: time (step 6) · config (step 7) · play/stop (step 15) · reset (step 16)
  • rows 1-4, steps 1-16: press to toggle triggers. playhead = brightest. in-loop steps brighter than out-of-loop. muted rows dim.
  • play/stop (row 7, step 15): toggles transport. disabled when external midi clock is active.
  • reset (row 7, step 16): all playheads to loop start. if running, immediately plays step 1.

note page

step 7 — row 8

7 rows = 7 scale degrees. row 1 = degree 7 (highest), row 7 = degree 1 (root).

  • note sync on: pressing a step sets note + trigger. pressing the same row again removes the trigger.
  • note sync off: sets note only. triggers are independent.
  • note quantization (tclk): when enabled per track, the pitch playhead advances on each trigger fire rather than each clock step.

duration page

step 9 — row 8

row 1: global multiplier · row 2: default/clear · rows 3-7: per-step bar (more = longer)
  • row 1, steps 1-16: global duration multiplier for the active track. step 9 = default (~1 step). step 16 = whole note. step 1 = very short.
  • row 2: shortest duration (staccato). rows 3-7: increasing length — row 7 = 100% of step.
  • note sync on: pressing a step sets duration + trigger. pressing same row again removes trigger.

velocity page

step 8 (second press) — blinks when active

per-step midi velocity. only trigger steps are shown.

row 1 = 127 · row 2 = 112 (default) · row 4 = 80 · row 6 = 40 · row 7 = 20
  • rows 1-7: press to set velocity for that step. row 1 = loudest, row 7 = quietest, row 2 = default.
  • note sync on: pressing a step sets velocity + trigger. pressing same row again removes trigger.

trigger ratchet

step 6 (second press) — blinks when active

subdivide steps into up to 5 individually toggled sub-triggers. only steps with triggers are interactive.

row 1: increment · rows 2-6: slots 5→1 · row 7: decrement
  • rows 2-6: toggle ratchet slots on/off. lit = fires, dim = rest. pressing a slot above the current count extends the count to include it.
  • row 1 tap: +1 subdivision (max 5). row 1 hold: fill all steps to max.
  • row 7 tap: -1 subdivision (min 1). row 7 hold: reset step to 1 subdivision.

alt note

step 7 (second press) — blinks when active

a parallel 16-step sequence with its own loop and clock division. each step holds a scale degree (0-6) that is added to the main note when a trigger fires. the combined index wraps within the scale.

row 1 = degree 6 · row 7 = degree 0 (unison, no change) · only trigger steps shown
  • rows 1-7: press to set scale degree for that step. row 1 = +6 degrees, row 7 = 0 (unison). pressing the same row sets that degree.
  • the alt note loop is shown and edited on the loop overlay when on this page.

loop overlay

step 11 — hold

rows 1-4: loop per track · in-loop triggers brighter · out-of-loop triggers dim · endpoints = brightest
  • setting a loop: first press = loop start, second press = end. loops can wrap (end left of start = wrap around step 16).
  • when on note or alt note page: shows the alt-note loop. all other pages: shows the trigger loop.
  • any track's loop can be edited, not just the active track.
  • mute: while holding loop (step 11), press a track button to toggle mute.

scale page

step 15 — hold

rows 1-4 steps 1-8: per-track settings · rows 1-6 steps 9-16: interval editor · rows 6-7 steps 1-8: presets · row 7 steps 9-16: root note

— per-track settings (rows 1-4)

  • step 1 (midi channel): tap to open channel select for that track — all 16 steps show channels 1-16. tap a channel to assign and close. tap step 1 again to cancel.
  • step 2 (note quantization): toggles tclk — pitch advances on trigger fires instead of clock steps.
  • steps 4-8 (direction): forward · reverse · pingpong · random walk · random.

— scale interval editor (rows 1-6, steps 9-16)

  • each row = one scale interval (semitones between consecutive degrees). steps 9-16 = 0-7 semitones. bright = current value.
  • press: set interval, rebuild scale, save to preset.
  • hold scale (step 15) + press interval: stretch mode — adjusts interval and compensates adjacent to preserve range.
  • press same interval twice: micro-adjust mode — shifts that degree's pitch without changing the preset.

— scale presets (rows 6-7, steps 1-8) · root note (row 7, steps 9-16)

  • 16 preset slots. bright = active. press to switch. presets 1-7 = musical modes, 8-16 = chromatic.
  • copy preset: press destination, then hold scale (step 15) + press source.
  • reset to factory: hold scale (step 15) + press a preset slot.
  • root note: row 7 steps 9-16 = chromatic positions (C through B).

pattern page

step 16 — hold

row 1: 16 pattern slots · row 2: cue clock length · row 7: file ops + transport
  • slot brightness: full = active · medium = saved · dim = empty · pulsing = cued.
  • short press: load immediately. hold ~1s: save to slot. hold ~3s: save + write to flash.
  • cue pattern: hold pattern button (step 16) + press slot. loads when cue clock expires.
  • row 2: manual cue clock length (1-16 steps). once set, pattern loads after this many steps of the longest active loop.
  • row 7 step 1: load all from flash (hold ~2s to confirm). step 2: clear mode — next slot press clears that slot. step 3: save all to flash (hold ~2s). step 15: play/stop. step 16: reset.

time page

hold step 6 — row 7

— internal clock

  • row 2 (rough bpm): steps 1-7 = 30-120 bpm (15 bpm steps) · steps 8-16 = 140-300 bpm (20 bpm steps).
  • row 3 (fine): +0 to +15 bpm offset.
  • row 4 steps 7-10: hold to nudge tempo. step 7 = -4, step 8 = -1, step 9 = +1, step 10 = +4 bpm.

— external midi clock

  • detected automatically. row 2 shows incoming bpm (read-only). row 3 steps 6-11: step resolution (8th notes → 16th triplets, default = 16th notes at step 8).

config page

hold step 7 — row 7

  • note sync (square icon, rows 3-6 steps 2-5): on = pressing a step on note, octave, duration, or velocity pages sets/removes both the parameter and the trigger together. off = parameters and triggers are independent.
  • loop sync — track (step 12, row 3): setting the trigger loop also updates the alt-note loop for that track.
  • loop sync — all (steps 11-14, row 6): all four tracks share loop points. default = on.
