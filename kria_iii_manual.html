kria iii

monome grid one - 4-track midi step sequencer - v1.4.0
based on ansible kria by monome

navigation

row 8

  • steps 1-4: select active track
  • step 6: trigger page. press again = ratchet sub-page (blinks). step 7: note page. press again = alt note (blinks). step 8: octave page. press again = velocity (blinks). step 9: duration page.
  • step 11: loop mod (hold). step 12: time division mod (hold). step 13: probability mod (hold).
  • step 15: scale page step 16: pattern page. when transport is running, step 16 pulses to beat.
  • mute: hold loop (step 11) + press a track button. muted tracks blink on all pages.
  • track copy: hold source track button, press destination — copies current page data.
  • track clear: hold track button ~2s - resets current page data for that track.
  • time / config / play / reset are also available while holding loop, time division, or probability mods.

trigger page

step 6

  • rows 1-4, steps 1-16: press to toggle triggers.
  • play/stop (row 7, step 15): toggles transport. disabled when external midi clock is active.
  • reset (row 7, step 16): all playheads to loop start. if running, immediately plays step 1.

note page

step 7

  • press a step: sets note for that step. 7 rows = 7 scale degrees. row 7 = degree 1 (root), row 1 = degree 7 (highest).
  • note quantization (scale page): when enabled per track, the pitch playhead advances on each trigger fire rather than each clock step.

trigger ratchet

step 6 (second press) - blinks when active

  • rows 2-6: toggle ratchet slots on/off. lit = fires, dim = rest. pressing a slot above the current count extends the count to include it.
  • row 1 tap: +1 subdivision (max 5). row 1 hold: fill all steps to max.
  • row 7 tap: -1 subdivision (min 1). row 7 hold: reset step to 1 subdivision.

alt note

step 7 (second press) - blinks when active

a parallel 16-step sequence with its own loop and clock division. each step holds a scale degree offset (0-6) added to the main note when a trigger fires. the combined index wraps within the scale.

  • rows 1-7: set degree offset for that step. row 7 = unison (no change). the alt note loop is shown and edited in the loop mod when on this page.

loop mod

step 11 - hold

rows 1-4: one row per track · active track brighter
  • setting a loop: first press = loop start, second press = loop end. loops can wrap — end left of start wraps around step 16.
  • on note or alt note page: shows and edits the alt-note loop. all other pages: shows the trigger loop.
  • any track's loop can be edited, not just the active track.
  • mute: while holding loop mod (step 11), press a track button to toggle mute.

scale page

step 15

- per-track settings (rows 1-4)

  • step 1 (midi channel): tap to open channel select for that track — all 16 steps show channels 1-16. tap a channel to assign and close.
  • step 2 (note quantization): toggle - pitch advances on trigger fires instead of clock steps.
  • steps 4-8 (direction): forward · reverse · pingpong · random walk · random.


- scale interval editor (rows 1-6, steps 9-16)

  • each row = one scale interval (semitones between consecutive degrees). steps 9-16 = 0-7 semitones. bright = current value.
  • press: set interval, rebuild scale, save to preset.
  • hold scale (step 15) + press interval: stretch mode - adjusts interval and compensates adjacent to preserve range.
  • press same interval twice: micro-adjust mode - shifts that degree's pitch without changing the preset.


- root note (row 7, steps 9-15)

  • steps 9-15 = white keys C through B. press once to select a natural root. press the same key again to sharpen it (C#, D#, F#, G# or A# - E and B have no sharp). a sharp root blinks. press again to return to natural.
  • step 16 (sharp shortcut): hold step 16 + press any root key to toggle sharp on/off immediately — useful when changing root live without double-tapping.
  • all notes across all tracks transpose to the new root immediately.


    • - scale presets (rows 6-7, steps 1-8)

    • 16 preset slots. bright = active. press to switch. presets 1-7 = musical modes, 8-16 = chromatic.
    • copy preset: press destination, then hold scale (step 15) + press source.
    • reset to factory: hold scale (step 15) + press a preset slot.

pattern page

step 16

  • row 1: 16 pattern slots · row 2: cue clock length · row 7: file ops + transport.
  • row 1: short press- load immediately. hold ~1s: save to slot. hold ~3s: save + write to flash.
  • cue pattern: hold pattern page button (step 16) + press slot. loads when cue clock expires.
  • row 2: manual cue clock length (1-16 steps). pattern loads after this many steps of the longest active loop.
  • row 7: step 1: load all from flash (hold ~2s - all saved slots flash on confirm). step 2: clear mode - hold step 2 + pattern slot clears that slot and removes it from flash. step 3: save all to flash (hold ~2s). step 15: play/stop. step 16: reset.

time page

hold step 6 - row 7

- internal clock:

  • row 2 (rough bpm): steps 1-7 = 30-120 bpm in 15 bpm steps · steps 8-16 = 140-300 bpm in 20 bpm steps. step 7 = default (120 bpm).
  • row 3 (fine): +0 to +15 bpm offset. step 1 = default (+0).
  • row 4 steps 7-10: hold to nudge tempo. step 7 = -4, step 8 = -1, step 9 = +1, step 10 = +4 bpm.

- external midi clock

  • detected automatically. row 2 shows incoming bpm (read-only). row 3 steps 6-11: step resolution (8th notes → 16th triplets, default = 16th notes at step 8).

config page

hold step 7 - row 7

  • note sync (square icon): on = pressing a step on the note, octave, duration, or velocity pages sets/removes both the parameter and the trigger together. off = parameters and triggers are independent.
  • loop sync - track (step 12, row 3): when setting a track's trigger loop, the alt-note loop for that track follows automatically.
  • loop sync - all (steps 11-14, row 6): all four tracks share loop points. default = on.

note: kria_iii syncs two loop layers per track (trigger and alt note). the original kria supports independent loops per parameter.
